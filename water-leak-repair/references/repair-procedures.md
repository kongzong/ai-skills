## 维修准备阶段

### 现场勘察与方案制定

```
【信息确认】
1. 复核漏水位置、范围、程度
2. 确认漏水根源（已完成诊断）
3. 评估修复难度和工程量
4. 与业主沟通修复方案和费用

【材料准备】
1. 根据修复方案列材料清单
2. 采购材料（品牌/规格/数量）
3. 材料到场验收（检查有效期/外观）
4. 现场材料存放（防潮/分类）

【工具准备】
1. 根据工艺要求准备工具
2. 检查设备状态
3. 准备安全防护用品
4. 应急物资准备（灭火器/急救包）

【现场保护】
1. 搬移家具家电
2. 铺设地面保护
3. 遮蔽不需要施工的区域
4. 设置施工警示
```

### 基面处理标准

```
【清理要求】
- 拆除损坏的装饰层至结构层
- 清除浮尘、松动颗粒、油污
- 裂缝内杂物清理干净
- 基面含水率<10%（防水施工前）

【修补要求】
- 结构裂缝先处理裂缝
- 蜂窝麻面用水泥砂浆修补
- 阴阳角用聚合物砂浆抹成R≥50mm圆弧
- 基面平整度偏差≤4mm/2m

【验收要点】
- 无空鼓、无起皮、无油污
- 基面坚实、干燥、洁净
- 细部节点处理到位
```

## 管道漏水修复

### 管道打压测试流程

```
【测试前准备】
1. 关闭入户总阀
2. 排空管道内余水
3. 隔离待测管道（关闭分阀门）
4. 安装压力表和打压泵

【打压操作】
1. 向管道内注水，排尽管内空气
2. 缓慢升压，每秒不超过0.1MPa
3. 升至测试压力（1.2-1.5MPa）
4. 稳压10分钟后检查接口
5. 继续稳压30分钟

【结果判定】
- 压降<0.05MPa：管道系统合格
- 压降≥0.05MPa：存在渗漏点
- 继续压降：严重泄漏

【漏点定位】
1. 逐段隔离测试缩小范围
2. 使用听漏仪定位
3. 必要时开凿验证
```

### PPR管热熔修复

```
【适用场景】PPR管砂眼、焊缝开裂、小范围破损

【操作步骤】
1. 关闭相关阀门，排空管道水
2. 标记破损位置，两侧各留出10cm余量
3. 用PPR剪刀或管割刀切除损坏段
4. 擦净管材和管件连接端
5. 热熔机加热（260±5℃）
6. 管材和管件同时插入热熔
7. 按规定时间加热、承插、冷却
8. 加热时间参考：
   - dn20：5秒
   - dn25：7秒
   - dn32：8秒
9. 恢复供水，检查是否渗漏

【注意事项】
- 热熔机温度必须稳定
- 管材管件必须同材质同规格
- 插入深度符合标准
- 禁止在潮湿环境下热熔
```

### 铝塑管卡套修复

```
【适用场景】铝塑管接头漏水、卡箍松动

【操作步骤】
1. 关闭阀门，排空管道水
2. 拆下漏水卡套
3. 检查管材端面是否变形
4. 切平管材端口（如需）
5. 套入新卡套和螺母
6. 插入管件，确保管材完全进入
7. 拧紧螺母（力度适中）
8. 恢复供水测试

【注意事项】
- 管材端口必须平整垂直
- 卡套方向正确（卡槽朝向管内）
- 密封垫圈完好
- 拧紧力矩适中，过紧会损伤管材
```

### 镀锌钢管修复

```
【适用场景】镀锌钢管锈蚀穿孔、丝口漏水

【方案一：换管】
1. 切割损坏管段
2. 套丝连接新管
3. 生料带缠绕密封
4. 恢复通水测试

【方案二：哈夫节】
1. 清理破损处表面
2. 安装哈夫节（带密封胶垫）
3. 均匀紧固螺栓
4. 恢复通水测试

【注意事项】
- 镀锌管禁止焊接（破坏镀锌层）
- 丝口连接需用生料带或液体螺纹胶
- 修复后做防腐处理
```

### 排水管修复

```
【PVC排水管】
1. 切除损坏段
2. 清理残胶
3. 涂PVC胶水
4. 套入新管件
5. 固定待干（至少30分钟）
6. 注水测试

【铸铁排水管】
1. 清理锈蚀部位
2. 用堵漏王或钢胶封堵小孔
3. 大面积损坏需换管段
4. 接口处用不锈钢抱箍

【注意事项】
- 排水管有坡度要求，修复不能破坏
- 粘接剂需完全固化后再通水
- 检查是否影响排水通畅
```

## 防水层修复

### 卫生间局部防水修复

```
【适用范围】防水层局部失效、瓷砖缝隙渗水

【施工步骤】

1. 拆除阶段
   - 拆除地漏周边300mm范围瓷砖
   - 拆除墙地接缝处瓷砖
   - 清理至结构层

2. 基面处理
   - 清理干净，无松动颗粒
   - 阴阳角抹成圆弧
   - 基面含水率<10%

3. 节点加强
   - 管根部位刷柔性防水涂料
   - 地漏周边做防水附加层
   - 墙地接缝做增强处理

4. 大面防水
   - 涂刷聚合物水泥防水涂料
   - 至少两遍，厚度≥1.5mm
   - 第二遍待第一遍表干后施工

5. 闭水试验
   - 蓄水深度3-5cm
   - 闭水48小时
   - 检查楼下及本层

6. 恢复装饰
   - 水泥砂浆保护层
   - 贴砖恢复
   - 勾缝密封

【材料推荐】
- 聚合物水泥防水涂料（JS-II型）
- 聚氨酯防水涂料
- 水泥基渗透结晶防水涂料
```

### 卫生间整体防水翻新

```
【适用范围】防水层大面积老化、多次局部修复无效

【施工步骤】

1. 拆除清理
   - 拆除全部瓷砖
   - 清除全部旧防水层
   - 清理至结构混凝土
   - 检查并修补结构裂缝

2. 基面处理
   - 基层修补平整
   - 阴阳角圆弧处理
   - 清洁干燥

3. 节点密封
   - 管根：刷防水涂料+无纺布增强
   - 地漏：防水层延伸至管壁
   - 门槛石：下方做防水止水带
   - 墙地面接缝：丁字缝增强处理

4. 防水层施工
   - 第一遍：薄涂打底
   - 第二遍：厚涂
   - 第三遍（如需）：检查遗漏
   - 总厚度≥1.5mm

5. 水泥砂浆保护层
   - 厚度≥20mm
   - 掺加防水剂
   - 找平压光

6. 闭水试验
   - 72小时闭水
   - 水位标记
   - 楼下检查

7. 贴砖恢复
   - 瓷砖铺贴
   - 专用勾缝剂
   - 美缝处理
```

### 阳台/露台防水修复

```
【适用范围】阳台、露台、屋面防水失效

【施工步骤】

1. 基层检查
   - 清除杂物、植被
   - 检查找坡层坡度
   - 修补起砂、空鼓

2. 节点处理
   - 女儿墙泛水：卷材上翻≥250mm
   - 落水口：防水层伸入管内
   - 变形缝：止水带检查或更换
   - 穿墙管：卷材收口密封

3. 防水层施工
   - 涂料类：涂刷两遍
   - 卷材类：热熔铺贴
   - 建议涂料+卷材复合

4. 保护层
   - 水泥砂浆保护层
   - 或保温层+保护层

5. 闭水试验
   - 蓄水深度5-10cm
   - 持续72小时
   - 检查室内对应位置
```

### 窗框防水修复

```
【适用范围】窗框渗水、窗台积水、密封失效

【施工步骤】

1. 清理旧密封
   - 剔除窗框内旧密封胶
   - 清理窗框内杂物

2. 检查窗框
   - 窗框变形情况
   - 固定螺丝是否松动
   - 组角缝隙是否密封

3. 缝隙处理
   - 窗框与墙体缝隙：发泡胶填充
   - 窗框与玻璃缝隙：重新打胶
   - 外侧收口：耐候密封胶

4. 防水加强
   - 窗框外侧刷防水涂料
   - 窗台找坡（外高内低）
   - 窗台外沿做滴水线

5. 恢复收口
   - 外墙涂料恢复
   - 窗台瓷砖铺贴（可选）

【材料选择】
- 耐候密封胶：硅酮耐候胶（建筑专用）
- 防水涂料：聚合物水泥防水涂料
- 发泡胶：阻燃型聚氨酯发泡胶
```

## 结构裂缝处理

### 混凝土裂缝注浆

```
【适用范围】建筑结构混凝土裂缝渗水

【材料选择】
- 水溶性聚氨酯注浆液（潮湿裂缝）
- 油溶性聚氨酯注浆液（干燥裂缝）
- 环氧树脂注浆液（结构加固）

【操作步骤】

1. 裂缝标记
   - 标注裂缝位置
   - 测量裂缝宽度和长度
   - 标记注浆点位置（间距15-20cm）

2. 裂缝清理
   - 沿裂缝开V型槽（宽10-15mm）
   - 清理碎屑和浮灰
   - 用气泵或吸尘器清理干净

3. 埋设注浆嘴
   - 在标记位置粘贴注浆嘴
   - 确保注浆嘴与裂缝连通
   - 裂缝两端封堵（禁止注浆嘴处）

4. 封缝处理
   - 沿裂缝涂环氧胶封闭表面
   - 确保密封严密
   - 待胶固化（约2-4小时）

5. 注浆操作
   - 连接注浆机和注浆嘴
   - 从低端向高端逐点注浆
   - 压力控制在0.2-0.5MPa
   - 观察邻孔出浆后停止
   - 移至下一注浆点

6. 清理固化
   - 注浆完成后待材料固化
   - 拆除注浆嘴
   - 表面打磨平整
   - 涂刷保护层

【质量标准】
- 注浆饱满度≥95%
- 裂缝内注浆材料连续无断点
- 表面无明显渗水痕迹
```

### 砖墙裂缝处理

```
【适用范围】砖砌体结构裂缝渗水

【施工步骤】

1. 裂缝评估
   - 判断裂缝性质（静止/发展）
   - 测量裂缝宽度
   - 判断是否涉及结构安全

2. 清理开槽
   - 沿裂缝凿槽（20-30mm宽）
   - 清理松动砖块
   - 浇水湿润基面

3. 注浆加固
   - 埋设注浆嘴
   - 注入水泥浆或聚合物浆液
   - 填充裂缝和空鼓

4. 表面修复
   - 水泥砂浆抹平
   - 挂钢丝网加强
   - 恢复装饰层

【注意事项】
- 结构性裂缝需先进行结构加固
- 温度裂缝可仅做表面处理
- 沉降裂缝需观察稳定后再处理
```

## 节点部位处理

### 管根防水加强

```
【标准做法】

1. 清理管根周边
   - 清除杂物和旧防水层
   - 管壁与楼板交界处剔槽（10mm深）

2. 堵漏灵抹弧
   - 用堵漏灵抹成R=15mm圆弧
   - 覆盖管壁和楼板各50mm

3. 刷防水涂料
   - 柔性防水涂料涂刷
   - 管壁向上延伸≥150mm
   - 地面向外延伸≥100mm

4. 铺增强布
   - 在涂层内嵌入无纺布
   - 做防水加强层

5. 二次防水
   - 再刷一遍防水涂料
   - 总厚度≥2mm
```

### 地漏周边防水

```
【标准做法】

1. 拆除地漏周边瓷砖
   - 范围：地漏周边300mm
   - 深度：至结构层

2. 清理检查
   - 清理地漏与楼板缝隙
   - 检查地漏是否松动

3. 缝隙处理
   - 用堵漏灵密封地漏与楼板间隙
   - 抹弧处理

4. 防水加强
   - 刷柔性防水涂料
   - 铺无纺布增强

5. 安装新地漏
   - 调整地漏标高
   - 确保排水坡度

6. 恢复瓷砖
   - 湿铺法贴砖
   - 留设美缝缝
```

### 阴阳角防水加强

```
【标准做法】

1. 清理基面
   - 清理浮灰和松动颗粒
   - 湿润基面（无明水）

2. 抹弧处理
   - 用聚合物水泥砂浆
   - 将阴阳角抹成R=50mm圆弧
   - 宽度≥50mm

3. 防水增强
   - 刷柔性防水涂料
   - 铺贴防水增强布
   - 再刷一遍涂料

4. 范围要求
   - 阴阳角两侧各延伸150mm
   - 形成可靠的防水加强区
```

## 修复后验收

### 闭水试验标准

```
【试验条件】
- 防水层完全固化（涂料类≥7天）
- 气温≥5℃
- 蓄水深度：30-50mm
- 闭水时间：48-72小时

【操作步骤】
1. 封堵地漏和排水口
2. 门槛石两侧做挡水坎
3. 缓慢注水至规定深度
4. 标记水位线
5. 定时观察水位变化
6. 检查楼下对应位置
7. 记录渗漏情况

【判定标准】
- 水位不下降 → 防水合格
- 水位下降≥20mm → 防水层失效
- 楼下出现水渍 → 渗漏点确认
```

### 打压测试验收

```
【验收标准】
- 压力值稳定在测试压力
- 30分钟内压降<0.05MPa
- 接口处无渗漏
- 修复段无渗漏
```

### 修复后观察期

```
【观察周期】
- 雨季：持续观察整个雨季
- 一般：修复后至少观察7天

【观察要点】
- 修复区域是否干燥
- 相邻墙面是否改善
- 楼下是否持续改善
- 是否出现新渗漏点

【合格标准】
- 修复区域完全干燥
- 含水率恢复至<5%
- 无复发迹象
- 楼下渗漏停止
```

### 维修档案建立

```
【档案内容】
1. 工程基本信息
   - 维修地址、房号、日期
   - 维修人员、联系方式

2. 诊断记录
   - 漏水位置和范围
   - 诊断过程和结论
   - 检测数据（照片/测量值）

3. 施工记录
   - 施工工艺和材料
   - 施工人员
   - 关键工序照片

4. 验收记录
   - 闭水试验结果
   - 打压测试结果
   - 修复前后对比照片

5. 质保信息
   - 质保期限
   - 质保范围
   - 售后服务联系方式

【存档要求】
- 纸质档案+电子档案
- 照片标注日期和位置
- 至少保存一个质保周期
```
