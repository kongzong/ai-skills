# 质量管理

> 📖 **这是后台深层参考**——新手日常用前台的[案例](case-study.md)/[playbook](playbook.md)/[模板](../templates/)即可，遇到下面情况再翻到这里。
> **何时翻到这里**：需要建立质量保证/质量控制机制与验收标准，或在 playbook #18（上线后线上频发）之后想把"质量"从上线前的突击变成全程内建。
> **它比 playbook/案例多讲**：质量规划→质量保证（过程）→质量控制（结果）的体系，以及配置管理、缺陷管理与运维交接的系统做法。

## 定义

作为项目经理与客户之间的协作活动，为定义并达成项目需求而制定计划并进行管理的所有活动；在质量体系中，与决定质量工作的策略、目标和责任的全部管理功能相关，并通过质量计划、质量保证和质量改进等手段完成。

## 一、启动阶段：设置质量管理环境

### 01 启动过程裁剪（Tailoring）
- **操作方式**：依据公司标准与步骤，对项目中使用的流程进行增删、变更与综合；请相关组织与专家参与；所有决定事项文档化，例外事项提出流程豁免（Waiver）。
- **交付物**：流程使用计划（依据裁剪）

### 02 制定初期配置管理计划
- 制定如何对交付物进行变更、控制与管理的计划；识别并文档化配置项；制作变更与控制步骤；检查人员配置；制作通知/报告相关记录。
- **内容**：配置管理步骤、存储库（Repository）、工具使用计划等。

### 03 制定初期度量计划
- 定义在项目中要收集的度量指标（Metrics），将收集与保存步骤具体化，描述分析与报告方法；以公司标准/步骤为基准制定，检查度量事项，更新度量要素。
- **理由**：实施中跟踪成果、为经理提供报告信息、更新纠正措施评价基准、为类似项目估算积累信息。

### 04 收集初期度量资料
- 收集制定度量计划所需的数据，作为基础资料；向成员说明度量资料与业务执行评价无关，仅用于后续预测与计划，以获取正确数据。

### 05 制定初期质量保证计划
- 制定基本评审标准与步骤，并制定必要评审与检查日程；确认执行任务是否符合项目并文档化；决定质量保证评审/检查日程与后期里程碑检查实施日程。

### 06 制定其他初期标准与步骤
- 确定项目的行政、管理、质量、技术等活动的其他初期标准与步骤（业务、计划、一致性检查、管理评审、工时记录、监控、项目管理、质量控制、报告、议题管理等）。

### 07 制作初期项目基准书
- 编制包含项目文件、输入物、交付物、步骤与标准的项目基准书；决定结构、制作标准、选定管理负责人、记录角色与职责、培训内容与方法。

### 08 检查初期项目环境符合性
- 执行主要作业前，审核初期项目控制计划、标准步骤与其他交付物；追加必要输入物（项目环境控制计划等）并调整。

## 二、计划阶段：改善质量管理环境

### 01 流程裁剪细化
- 将选定的流程按项目要求细化裁剪；参考公司内部方法论知识库与全公司标准方法论的裁剪指南。

### 02 配置管理计划细化
- 检查初期配置管理计划与步骤，细化配置管理任务（尤其变更管理步骤）；更新项目基准书；确认项目特性、范围、方向与初期计划一致；明确变更管理委员会成员、步骤与职责。

### 03 设置基线的配置库
- 制定配置管理基线库（Check Point：库的位置、访问管理者、权限管理、包含的交付物、基线版本管理、交付物检入/检出方式）；建立项目管理台账。

### 04 度量计划细化
- 检查启动阶段度量交付物，确认初期度量计划形成的目标是否有效；细化新度量指标的数据目录与详细水平；文档化假设/制约/议题。

### 05 质量保证计划细化
- 细化质量保证评审/检查日程与标准。

### 06 项目基准书标准细化
- 细化项目基准书的标准与步骤。

## 三、实施 / 控制阶段：实施质量管理活动

- 按质量计划开展质量保证与质量控制活动；通过评审、检查、测试验证交付物符合需求；将质量度量数据纳入监控。

## 四、结束阶段：质量控制结束

- 确认质量目标达成；将质量管理经验教训纳入项目复盘。

## 阶段活动汇总

```
启动：设置质量管理环境（裁剪 / 配置管理 / 度量 / 度量资料 / 质量保证 / 其他标准 / 基准书 / 符合性检查）
计划：改善质量管理环境（裁剪细化 / 配置细化 / 基线库 / 度量细化 / 质量保证细化 / 基准书细化）
实施控制：实施质量管理活动
结束：质量控制结束
```
