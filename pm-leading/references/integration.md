# 整合管理

> 📖 **这是后台深层参考**——新手日常用前台的[案例](case-study.md)/[playbook](playbook.md)/[模板](../templates/)即可，遇到下面情况再翻到这里。
> **何时翻到这里**：需要统筹全局——把各领域计划整合成一份总计划、管理变更与基线、或做项目收尾，或在 playbook #12（临时加需求）/#13（接烂摊子）之后想从全局视角重建秩序。
> **它比 playbook/案例多讲**：整体项目计划的整合、变更控制流程（变更请求→影响评估→批准→更新基线）、项目收尾与经验归档；它是把其余 8 大领域"串起来"的总纲。

## 定义

协调项目各知识领域与所有构成要素，使项目作为一个整体运转的管理活动。它贯穿启动、计划、实施、控制、结束全过程，是其他八个领域的中枢。

## 一、启动阶段：综合项目构成要素

- 将范围、进度、成本、风险、沟通、质量、人力、采购各领域的启动活动整合，形成统一的项目启动框架。
- 明确项目目标与约束，建立项目章程式的整体认知。

## 二、计划阶段：综合细化与基线设置

- 将各领域的计划要素综合细化，确保相互一致（如风险计划纳入成本/进度/资源，质量基准纳入整体基准书）。
- 组织项目计划审核，设置项目基线（范围基线、进度基线、成本基线）。
- **关键产出**：项目基准书（整合流程、标准、政策的集成文件）。

## 三、实施阶段：实施项目计划要素

- 按整合后的项目计划执行各要素；保持各领域活动协调推进。

## 四、控制阶段：监控与再计划

- 监控项目计划各构成要素的执行状况，发现偏差时启动再计划（经变更管理步骤更新基线）。
- 维护整体项目台账与状态报告。

## 五、结束阶段：事后审核

- 确认项目是否达到初期目的；事后审核项目里程碑与整体成果。
- 推动经验教训汇总与知识复用。

## 与其他领域的关系

| 领域 | 整合管理关注点 |
|------|----------------|
| 范围 | 范围基线与变更控制中枢 |
| 进度 | 进度基线、关键路径与整体协调 |
| 成本 | 成本基线与预算整合 |
| 风险 | 风险计划融入其他计划要素 |
| 沟通 | 整体信息分发与干系人协调 |
| 质量 | 项目基准书与配置管理集成 |
| 人力 | 团队计划与组织图整合 |
| 采购 | 合作企业计划纳入整体计划 |

## 阶段活动汇总

```
启动：综合项目构成要素
计划：综合细化 + 计划审核与基线设置
实施：实施项目计划要素
控制：监控与再计划
结束：事后审核里程碑
```
