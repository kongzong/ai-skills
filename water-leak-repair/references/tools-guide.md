## 检测仪器

### 1. 热成像仪

**型号推荐**：FLIR E4 / FLIR E8 / 德力西红外热像仪

**核心功能**：
- 显示墙面/地面温度分布，漏水区域因水分蒸发温度偏低
- 快速定位隐藏管道走向
- 非接触式检测，不破坏装修

**使用方法**：

```
1. 预热设备（开机等待2-3分钟）
2. 设置热成像参数：
   - 发射率：0.95（墙面）
   - 温度范围：15-35°C
3. 与干燥墙面对比拍摄
4. 分析热成像图：深蓝色/紫色区域为可疑漏水区
5. 记录异常区域位置
```

**读取时机**：完成初步目视检查后，对可疑区域进行深度探测

**注意事项**：
- 环境温差越大效果越明显（建议关闭空调/暖气）
- 检测前24小时内对应区域避免用水
- 墙体材质影响：瓷砖温度变化不明显，需配合其他工具

### 2. 管道打压泵

**型号推荐**：渝工牌打压泵 / 史丹利手动打压泵 / 威乐电动打压泵

**核心功能**：
- 对给水管道进行压力测试
- 验证管道系统密封性
- 判断管道是否存在暗漏

**使用方法**：

```
1. 关闭入户总阀，排空管道内余水
2. 连接打压泵到任一出水口
3. 向管道内注水排气
4. 缓慢加压至工作压力的1.5倍
   - 普通住宅：0.8-1.0MPa
   - 测试压力：1.2-1.5MPa
5. 保压30分钟，记录压力值
6. 判断标准：
   - 压降<0.05MPa：合格
   - 压降>0.05MPa：存在渗漏
```

**读取时机**：怀疑管道漏水时首选检测工具

**注意事项**：
- 打压前确认管道材质耐压能力
- PPR管需热熔修复，铝塑管可单独隔离测试
- 打压后及时泄压，避免长时间高压

### 3. 听漏仪/听漏棒

**型号推荐**：自来水听漏仪 / 日本共和听漏棒 / 国产经济型听漏仪

**核心功能**：
- 放大管道漏水声
- 定位埋地管/墙内管的暗漏点
- 精度可达10cm以内

**使用方法**：

```
1. 听漏棒（简易型）：
   - 将探头接触管道路经位置
   - 耳朵贴近棒口倾听
   - 漏水声特征：嘶嘶声/咕噜声/间歇性滴水声

2. 电子听漏仪（精密型）：
   - 佩戴耳机
   - 在地面/墙面移动探头
   - 声压最大处即为漏水点
   - 必要时进行二次精确定位
```

**读取时机**：打压测试确认管道漏水后，定位具体漏点

**注意事项**：
- 夜间安静环境效果最佳（22:00-06:00）
- 排除其他水源干扰（空调冷凝水、下水管）
- 金属管声音传导更好，非金属管衰减严重

---

### 4. 内窥镜（管道探测仪）

**型号推荐**：得力工业内窥镜 / 弘利硬杆内窥镜 / 无线wifi内窥镜

**核心功能**：
- 探查墙内、地埋、排水管内部状况
- 查看裂缝、脱层、腐蚀、堵塞
- 确认管道材质和接口状态

**使用方法**：

```
1. 根据探查位置选择镜头角度（直头/斜头）
2. 涂抹适量润滑剂
3. 从预留孔、打孔处或拆开管件处插入
4. 缓慢推进，观察显示屏
5. 记录发现：裂缝位置、腐蚀程度、异物情况
```

**读取时机**：需要查看封闭空间内部状况时使用

**注意事项**：
- 选择合适直径的探头，过粗损坏管道，过细看不清
- 提前了解管道走向，避免误入歧途
- 排水管检测需注意卫生

---

### 5. 电子湿度计

**型号推荐**：得力温湿度计 / 标智多合一检测仪 / 希玛数字湿度仪

**核心功能**：
- 测量墙面/地面含水率
- 量化潮湿程度，追踪干燥进程
- 辅助判断修复效果

**使用方法**：

```
1. 校准仪器（使用标准校准板或干燥环境归零）
2. 探头紧贴墙面/地面
3. 等待读数稳定（约10-15秒）
4. 记录数据并标注位置
5. 正常值参考：
   - 干燥墙面：<5%
   - 轻微潮湿：5-15%
   - 明显潮湿：15-25%
   - 严重渗水：>25%
```

**读取时机**：贯穿整个检测和修复过程

**注意事项**：
- 不同材质基准值不同（木材与水泥差异大）
- 多点测量取平均值
- 修复后需确认含水率恢复至正常范围

## 测量工具

### 6. 激光测距仪

**型号推荐**：得力激光测距仪 / 博世GLM4000 / 徕卡D2

**核心功能**：
- 精确测量距离
- 计算面积体积
- 记录泄漏点与参照物的位置关系

**使用方法**：
```
1. 开机校准
2. 选择测量模式（单次/连续/面积）
3. 对准目标点，按测量键
4. 记录数据
```

---

### 7. 水压表

**型号推荐**：普通压力表0-1.0MPa / 数字水压表

**核心功能**：
- 安装在用水点监测水压
- 判断水压是否异常
- 排查水压过高导致的渗漏

**使用方法**：
```
1. 关闭出水口阀门
2. 连接水压表到接口
3. 打开阀门读取压力值
4. 正常水压：0.1-0.4MPa
```

---

### 8. 塞尺/缝隙规

**型号推荐**：得力塞尺组 / 10片式钢片塞尺

**核心功能**：
- 测量裂缝宽度
- 评估缝隙大小
- 判断是否需要注浆处理

## 施工工具

### 9. 电锤/冲击钻

**型号推荐**：博世GBH2-28 / 牧田DH18DBL / 史丹利电锤

**核心功能**：
- 墙面开槽布管
- 剔除损坏的瓷砖/防水层
- 钻孔安装固定件

**使用方法**：

```
1. 选择合适钻头（瓷砖开孔用玻璃钻头，混凝土用电锤钻头）
2. 调低转速（瓷砖），调高冲击（混凝土）
3. 垂直墙面均匀用力
4. 避免在同一点长时间冲击
```

**注意事项**：
- 开槽前确认墙内管线走向
- 瓷砖面先用电钻低速打穿釉面再换冲击

---

### 10. 角磨机

**型号推荐**：博世GWS700 / 史丹利9555 / 牧田GA4530

**核心功能**：
- 切割瓷砖
- 开槽修整
- 去除旧防水层

**使用方法**：
```
1. 安装合适切割片（瓷砖用金刚石切割片）
2. 佩戴护目镜和手套
3. 沿标线匀速切割
4. 切割时浇水冷却
```

---

### 11. 防水喷枪

**型号推荐**：高压防水喷枪 / 防水涂料喷涂机

**核心功能**：
- 喷涂防水涂料
- 均匀覆盖施工面
- 提高施工效率

---

### 12. 注浆机/注浆针头

**型号推荐**：手动注浆器 / 电动高压注浆机

**核心功能**：
- 向裂缝内注入防水浆液
- 填充空鼓和蜂窝结构
- 加压封堵渗水通道

**使用方法**：

```
1. 清理裂缝表面
2. 预埋注浆针头（间距15-20cm）
3. 调配注浆材料（水溶性/油溶性聚氨酯）
4. 低压缓慢注入，观察出浆
5. 注满后拔出针头，表面封闭
```

---

### 13. 壁纸刀/美工刀

**型号推荐**：得力4810 / 田岛TTA-S / 瑞士力刀

**核心功能**：
- 切割防水卷材
- 裁剪密封胶
- 清理接缝杂物

---

### 14. 抹灰工具组

**型号**：不锈钢抹子 / 阴阳角抹子 / 找平尺

**核心功能**：
- 批刮防水砂浆
- 抹平基面
- 阴阳角圆弧处理

## 工具选型原则

### 按场景选择

| 场景 | 必备工具 | 选配工具 |
|------|----------|----------|
| 管道暗漏排查 | 打压泵、听漏仪 | 热成像仪、内窥镜 |
| 防水层失效检测 | 湿度计 | 热成像仪、闭水试验设备 |
| 结构裂缝检查 | 目视+放大镜 | 塞尺、裂缝观测仪 |
| 屋面渗漏检测 | 目视+雨水追踪 | 无人机航拍（大型屋面） |
| 日常小修 | 电锤、角磨机、注浆工具 | 按需配置 |

### 按预算选择

| 预算档位 | 推荐配置 |
|----------|----------|
| 入门级 | 湿度计、卷尺、强光手电、基础手动工具 |
| 专业级 | 增加：热成像仪、打压泵、听漏棒 |
| 全能级 | 完整配置+内窥镜、高端检测设备 |
