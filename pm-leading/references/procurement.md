# 采购管理

> 📖 **这是后台深层参考**——新手日常用前台的[案例](case-study.md)/[playbook](playbook.md)/[模板](../templates/)即可，遇到下面情况再翻到这里。
> **何时翻到这里**：项目涉及外包、供应商、采购合同或跨公司协作，或在 playbook #5（供应商拖延）之后想把外部依赖正式管起来。纯内部项目可略过。
> **它比 playbook/案例多讲**：采购全流程（采购计划→选商→签合同→合同执行与验收→收尾），合作方作用与责任界定、验收标准约定；playbook 教你催拖延，这里教你从一开始就把外部依赖框住。

## 定义

管理从外部获取产品、服务或成果的过程，包括工具/材料/服务的采购以及合作企业的选择与管理。

## 一、启动阶段：考虑采购必要性

### 01 选定项目初期工具
- **操作方式**：确认项目必要的工具类型，定义评价选择标准；资源采购与配置计划结合，资源管理相结合制定工具应用培训计划。
- **交付物**：资源采购与配置计划

### 02 采购材料与服务
- 制定选定计划，定义并更新合作企业的作用与责任及相关项目计划书；确认采购必要性。

## 二、计划阶段：修改采购管理计划

### 01 细化工具选定
- 更新采购管理作业交付物，协商项目所需外部资源事项。

### 02 采购增加材料与服务
- 根据需要追加采购材料与服务；更新资源移动计划（考虑办公环境、便利设施等）。

### 03 细化合作企业业务范围
- 明确验收标准、交付物、步骤与评价标准等内容。

### 04 选择合作企业
- 按评价标准选择合作企业；将合作企业作用、责任定义并更新进项目计划书。

### 05 制作并细化合作企业业务协议书
- 制作并细化与合作企业的业务协议书（含验收标准、交付物、步骤、评价）；文档化。

### 06 反映合作企业计划
- 计划如何将合作企业项目计划反映在整体项目计划中；更新采购管理作业交付物。

## 三、实施 / 控制阶段：合作企业管理

### 01 合作企业成果测定及监控
- 对合作企业提供的产品与服务实施成果测定与监控。

### 02 议题管理及制作变更请求书
- 管理合作企业相关议题；必要时制作合作企业变更请求书（若解决方案为终止合作，则文档化终止合同的变更请求）。

### 03 合作企业发票处理
- 接受合作企业付款申请书，按合同条件支付款项；在约定条件内支付合同金额。

## 四、结束阶段：结束与合作企业合同

### 01 结束业务合议
- 验证合同事项已满足；合作企业须满足结束条件方可向我方提交；若解除合同将其理由写入评价书；解除不再需要的服务合同，通知合同解除。

### 02 资源再分配
- 再分配不再需要的硬件/软件资产；为项目结束解除所有合同事项；释放资源。

## 阶段活动汇总

```
启动：考虑采购必要性（选定初期工具 / 采购材料服务）
计划：修改采购管理计划（细化工具 / 增加采购 / 细化范围 / 选择合作企业 / 业务协议 / 反映计划）
实施控制：合作企业管理（成果测定 / 议题与变更 / 发票处理）
结束：结束合作企业合同（结束合议 / 资源再分配）
```
