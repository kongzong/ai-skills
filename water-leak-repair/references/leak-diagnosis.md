## 漏水分类体系

### 按水源分类

| 类型 | 特征 | 排查方向 |
|------|------|----------|
| **给水管漏水** | 持续不断、水量稳定、与用水无关 | 打压测试+听漏定位 |
| **排水管漏水** | 间断性、伴异味、通常与排水行为相关 | 染色试验+内窥镜 |
| **防水层失效** | 与用水时间相关、蔓延性扩散 | 闭水试验+湿度分布图 |
| **冷凝水** | 温差大时明显、干燥天气减轻 | 温湿度监测 |
| **结构渗水** | 雨季加重、线性水痕 | 雨天追踪+外墙面检查 |
| **混合型** | 多种因素叠加 | 逐项排查、综合判断 |

### 按位置分类

| 位置 | 常见漏水类型 | 高频原因 |
|------|-------------|----------|
| **卫生间** | 防水层失效、管道暗漏、地漏周边、门槛石渗水 | 防水层老化、管道接口松动、排水不畅 |
| **厨房** | 管道接口、防水失效、烟道根部 | 角阀漏水、洗碗机接口、排水管渗漏 |
| **阳台** | 防水层失效、窗框渗水、排水管问题 | 防水收口不当、密封胶老化、地漏堵塞 |
| **外墙** | 结构裂缝、装饰构件渗水 | 热胀冷缩裂缝、瓷砖空鼓、空调孔渗水 |
| **屋顶** | 防水层老化、节点渗漏、天沟堵塞 | 卷材老化、落水口松动、女儿墙泛水失效 |
| **窗框** | 密封失效、外墙渗入 | 密封胶开裂、窗框变形、外墙裂缝导水 |
| **地下室** | 结构渗水、沉降缝、穿墙管 | 混凝土裂缝、止水带失效、水压过高 |
| **管道井** | 公共管道漏水、水表箱渗水 | 管道锈蚀、阀门渗漏、保温层凝露 |

## 三段式诊断法详解

### 第一阶段：问诊（信息收集）

**核心原则**：80%的漏水诊断靠问诊就能确定方向

**问诊清单**：

```
【基础信息】
□ 漏水位置：哪个房间？哪个墙面/地面？
□ 首次发现时间：什么时候开始的？
□ 发现时的天气：晴天/雨天/雨天过后？
□ 发现时的用水情况：有人在用水/无人用水/所有人都不在？

【变化规律】
□ 时间规律：
  - 24小时都在漏？
  - 集中在某个时段？
  - 用水后加重？
  - 雨天加重？
□ 季节规律：
  - 全年持续？
  - 雨季明显？
  - 冬季明显（可能冷凝水）？

【水渍特征】
□ 颜色：清水/发黄/发黑/发绿（可能藻类）
□ 气味：无异味/臭鸡蛋味（污水）/霉味
□ 形态：滴水/渗水/流淌/潮湿痕迹
□ 干湿变化：一直湿/干了又湿/逐渐变干

【历史追溯】
□ 楼上/隔壁是否有漏水历史？
□ 房屋年龄？装修时间？
□ 之前是否维修过？维修方案是什么？
□ 是否改造过水电？（暗埋管道增加）
□ 是否改过结构？（敲墙、开槽、打孔）
```

**信息价值判断**：

| 问诊结果 | 初步判断 |
|----------|----------|
| 雨天加重，晴天减轻 | 结构渗水/外墙渗漏 |
| 用水后加重，晚上加重 | 给水管暗漏（持续压力） |
| 洗澡后加重 | 防水层失效/地漏周边 |
| 楼上没人用水但持续漏 | 公共管道/楼栋主立管 |
| 水渍蔓延扩大 | 防水层大面积失效 |
| 水渍固定在某处 | 局部管道漏水点 |
| 异味伴随 | 排水管渗漏或防水层以下积水 |

### 第二阶段：排查（工具辅助）

**排查优先级原则**：

```
优先顺序：
1. 目视检查 —— 无成本、无破坏
2. 湿度检测 —— 低成本、定量数据
3. 闭水试验 —— 针对防水层
4. 打压测试 —— 针对管道
5. 热成像/听漏 —— 高成本、精准定位
6. 开凿验证 —— 万不得已、破坏性确认
```

**目视检查要点**：

```
【可见裂缝识别】
□ 位置：墙面/地面/阴阳角/管道周边
□ 形态：直线裂缝/不规则裂缝/网状裂缝
□ 走向：水平裂缝（多为沉降）/垂直裂缝（多为收缩）
□ 宽度：头发丝级/可见缝隙/明显张口
□ 活动性：静止裂缝/正在发展的裂缝

【泛碱现象】
□ 位置：墙面底部、踢脚线位置
□ 形态：白色粉末/结晶状/绒毛状
□ 含义：水分从墙体内部向外迁移，碱性物质析出
□ 程度：轻度（粉末可擦除）/中度（结晶覆盖）/重度（起皮脱落）

【水渍形态分析】
□ 扩散形态：圆形（点漏）/扇形（线漏）/不规则（面漏）
□ 边界特征：清晰（近期漏水）/模糊扩散（历史积水）
□ 颜色深浅：深色（持续漏水）/浅色（偶发漏水）

【装饰层异常】
□ 乳胶漆：起泡、脱落、变色
□ 壁纸：鼓包、发霉、翘边
□ 瓷砖：空鼓（敲击声音变化）、勾缝剂变色
□ 木地板：变色、起拱、发软
```

**湿度检测标准操作**：

```
检测流程：
1. 建立基准区：选取干燥墙面测量3点取平均（基准值）
2. 网格化检测：以30cm×30cm网格标记检测点
3. 逐点测量：探头紧贴墙面，等待读数稳定（10-15秒）
4. 绘制湿度分布图：用色块标注各点数据
5. 异常标注：>5%区域画圈标记

湿度读数参考：
- 0-5%：干燥，正常
- 5-15%：轻微潮湿，需关注
- 15-25%：明显潮湿，疑似漏水区域
- >25%：严重渗水，优先排查区域

注意事项：
- 不同材质基准值不同（水泥vs瓷砖vs木材）
- 冬季低温时水分蒸发慢，读数可能偏高
- 检测前24小时避免该区域用水
```

### 第三阶段：确诊（验证定位）

**管道漏水分步验证**：

```
第一步：关闭所有用水设备
□ 确认所有水龙头关闭
□ 确认马桶、热水器无运行
□ 查看水表指针是否转动

第二步：打压测试
□ 隔离待测管道系统
□ 注水排气
□ 缓慢加压至1.2-1.5MPa
□ 保压30分钟
□ 判断结果：压降<0.05MPa为合格

第三步：漏点定位
□ 打压确认渗漏后，使用听漏仪
□ 夜间安静时段效果最佳
□ 沿管道路由逐点监听
□ 声压峰值点即为漏点
□ 必要时用热成像辅助验证

第四步：开凿验证
□ 在漏点正上方开小孔
□ 用内窥镜确认管道状态
□ 确定修复方案
```

**防水层失效验证**：

```
闭水试验标准流程：
1. 封堵地漏、门槛石两侧做挡水坎
2. 蓄水深度3-5cm
3. 标记水位线
4. 持续48小时
5. 观察楼下是否渗水
6. 同时观察本层水位变化

结果判断：
- 本层水位明显下降 + 楼下渗水 → 防水层失效
- 本层水位下降 + 楼下不渗 → 本层防水局部问题
- 本层水位稳定 + 楼下渗水 → 楼板有裂缝或穿层管道
```

## 分层排查逻辑树

### 快速判断流程

```
漏水问题
│
├─ 是雨后加重吗？
│  ├─ YES → 排查结构渗水（外墙/屋面/窗框）
│  └─ NO → 进入下一步
│
├─ 是否与用水行为相关？
│  ├─ YES → 排查防水层/排水管
│  └─ NO → 进入下一步
│
├─ 是否持续不断？
│  ├─ YES → 排查给水管（打压测试）
│  └─ NO → 排查间歇性水源
│
└─ 是否有异味？
   ├─ YES → 排查排水管/污水渗漏
   └─ NO → 可能是清水管或冷凝水
```

### 卫生间专项排查

```
卫生间漏水排查路径：

【问诊阶段】
□ 是否洗澡后加重？→ 防水层/地漏嫌疑
□ 是否马桶冲水后加重？→ 排污管/马桶密封嫌疑
□ 是否洗脸时加重？→ 台盆下水管/角阀嫌疑
□ 是否全天持续？→ 给水管嫌疑

【分区检测】
□ 门槛石周边：检查密封是否失效
□ 地漏周边：注水测试是否顺畅
□ 墙地接缝：检查瓷砖勾缝剂
□ 管道穿楼板：检查套管密封

【打压测试】
□ 冷水管单独打压
□ 热水管单独打压
□ 排除法定位问题管道
```

### 外墙渗漏专项排查

```
外墙漏水排查路径：

【外部检查】
□ 外墙面：找裂缝、空鼓、脱层
□ 装饰构件：腰线、空调板、线条
□ 节点部位：窗框周边、阳台栏板根部
□ 屋面泛水：女儿墙、烟道、通气管根部

【内部验证】
□ 描绘水渍边界（拍照记录）
□ 雨天追踪：外部泼水模拟
□ 热成像：外保温层含水检测

【修复优先级】
1. 结构裂缝：压力注浆
2. 节点渗水：重新做防水收口
3. 大面积失效：整体防水翻新
```

## 常见漏水模式识别

### 模式一：点状滴水

**特征**：固定位置持续滴水或渗水

**最可能原因**：
1. 管道穿楼板处套管密封失效
2. 暗埋管道有砂眼或焊缝开裂
3. 冷凝水滴落（非真正漏水）

**排查重点**：打压测试 + 听漏定位

---

### 模式二：线性水痕

**特征**：沿墙面或天花板出现线性水渍

**最可能原因**：
1. 水平裂缝（沉降或收缩）
2. 管道沿程渗漏
3. 防水层收口失效

**排查重点**：热成像追踪走向 + 开凿验证

---

### 模式三：扩散性水渍

**特征**：水渍边界模糊，逐渐扩大

**最可能原因**：
1. 防水层大面积失效
2. 保温层/找平层内含水
3. 慢渗型裂缝

**排查重点**：湿度分布图 + 闭水试验

---

### 模式四：间歇性渗水

**特征**：一段时间有水，一段时间干燥

**最可能原因**：
1. 排水管渗漏（仅排水时漏水）
2. 屋面/外墙渗漏（仅雨季）
3. 冷凝水（仅温差大时）

**排查重点**：记录时间规律 + 针对性试验

---

### 模式五：泛碱发霉

**特征**：墙面底部白色粉末或黑色霉斑

**最可能原因**：
1. 墙体内部水分蒸发带出碱性物质
2. 长期潮湿导致霉菌滋生
3. 可能是表面现象，根源在别处

**排查重点**：湿度检测追查水源 + 墙体干燥处理

## 渗水路径分析

### 水流规律

```
【垂直渗透】
雨水/用水水 → 找平层 → 结构层 → 天花板滴水
     ↓
上层地面 → 楼板裂缝/穿管缝隙 → 下层天花板

【水平蔓延】
漏水点 → 沿墙体/地面扩散 → 远离源头的水渍
     ↓
原因：毛细作用 + 装饰层吸附 + 保温层蓄水

【沿管道爬升】
管道渗漏 → 水沿管道外壁向上爬升 → 远离漏水点的墙面潮湿
```

### 路径追踪方法

```
1. 绘制水渍分布图
   - 拍照记录全貌
   - 标注边界形态
   - 标记最深点位置

2. 逆向追踪
   - 从最严重的水渍处开始
   - 沿扩散方向逆向追溯
   - 寻找可能的渗水源头

3. 结合管道路由
   - 了解暗埋管道走向
   - 对照水渍分布
   - 寻找交叉点

4. 使用辅助工具
   - 热成像：显示水分扩散路径
   - 湿度计：梯度测量定位边界
```

### 典型案例分析

**案例1：卫生间门口墙根发霉**
```
现象：卫生间门口两侧墙面底部发霉、泛碱
分析：
- 门槛石未做防水挡边
- 洗澡水从门槛石下方窜出
- 沿墙角蔓延到相邻房间

诊断：门槛石防水失效
修复：门槛石重新做防水+门槛石下重新铺贴
```

**案例2：卧室天花板角落滴水**
```
现象：卧室天花板角落每逢大雨就滴水
分析：
- 位置对应外墙
- 雨天加重，晴天减轻
- 楼上无住户，排除楼上漏水

诊断：外墙渗漏
修复：外墙面做防水/裂缝注浆+屋面檐口修复
```

**案例3：厨房吊柜内发霉**
```
现象：橱柜内背板发霉，木板膨胀
分析：
- 仅橱柜内严重
- 周围墙面无明显异常
- 位置靠近烟道

诊断：烟道根部防水失效，雨水沿烟道外壁渗入
修复：屋面烟道泛水重新处理+室内烟道根部防水
```
